# 地脉投影仪投影表实测

第五批集成（2026-09-29）做的一次实测，结果填进了 `../ley_projector_tables.py` 的 `TABLES` / `ROCK`。

## 复现

```
python tools/gen/ley_projector/survey.py      # 工程根目录（要起 Gradle 和本地端口）；约 3 分钟（Gradle 配置 + 开服 + 生成）
```

- `survey.py`：临时改 `run/server.properties`（存档名 `ley_survey_b5`、种子 20260929、只听 127.0.0.1、端口 25997 / RCON 25998、关看门狗），
  没有 `run/eula.txt` 就临时写一个，后台 `gradlew runServer`，RCON 连上后在主世界、下界各 `forceload add` 以 (0, 0) 为中心的 25×25 区块，
  每分钟 `save-all flush` 数一次生成完的区块，齐了就 `stop`；最后还原 server.properties、删临时 eula，跑 `blockcount.py`。
  不碰 `run/world` 和 `run/saves`。`run/mods` 里的 TestHelper 会跟着加载（专用服上正常启动，已实测）。
- `blockcount.py <存档>`：只读区域文件，统计主世界 y −64~63、下界 y 0~127 的方块成分，只算自己和周围 8 块都生成完的区块
  （矿脉会从邻居长过来，边上的区块偏少）。「能投影的方块」= 除空气、水、岩浆、基岩、火以外的方块。结果写 `survey_result.json`。
- 要换种子或范围：改 `survey.py` 顶上的常量，删掉 `run/ley_survey_b5` 再跑。存档留着的话脚本直接统计、不重新生成（没生成完会提示区块数不够）。
- **被打断以后**（外层超时硬杀 python 不走 finally）：`run/server.properties` 停在改过的样子（存档名 ley_survey_b5、关正版验证、开 RCON），
  备份在 `run/server.properties.survey_backup`，临时 eula 带标记 `run/eula.txt.survey_made`。下次跑 `survey.py` 一开头会按它们还原然后退出；
  重跑之前先查有没有留下的 runServer / Gradle 进程（杀掉 python 杀不到子进程；按命令行核对是本工程的 java 再结束），不然会抢端口和存档。
  同一时间只跑一个 `survey.py`。
