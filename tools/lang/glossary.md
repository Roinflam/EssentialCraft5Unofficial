# 源质魔法5 术语表（汉化本土化）

配套文件：`zh_cn_overrides.json`（原作英文键 → 新中文，626 条），`hardcoded_strings.md`（原作写死在代码里的英文、覆盖说明、英文修正建议）。

**基准**：原作 `zh_CN.lang`。MC百科「源质魔法4非官方版」物品列表里的名字和它一致，所以「沿用原作」就等于「沿用社区叫法」。
本表只借用了名字，没有照搬 MC百科的任何说明文字（它是 BY-NC-SA，和本模组的 CC BY-SA 不兼容）。

改名原则：老玩家认得的、没错的就不动；**误译**（如「无效的核心」「物流核心」「菱形板」）、**同一个词多种译法**（冻结/冰冻/霜冻，污染/腐败/腐化）、
**机翻腔和不成词的**（「风灵之焦」「灵魂划刀」）、**与原版官方中文冲突的**（「手杖」译 Mace，「掉落伤害」）才改。

## 一、排版与用词规则

1. **缩写保留英文**：MRU、UBMRU、MRUCU、ESPE、MROV、Boss、D6。与汉字之间加半角空格（「MRU 水晶」「消耗 20 MRU」），与全角标点之间不加（「目标没有 MRU！」）。
2. **数字**：与汉字之间加空格（「可跳 3 格高」「410 路公交车票」）；`%`、`°` 紧跟数字（「10%」「%s°C」）；与英文单位之间加空格（「%s MRU/t」）；全角冒号后不加空格（「高度：-1」）。
3. **占位符**：`%s` 代表数字时按第 2 条加空格；代表玩家名、物品名时跟原版一样不加空格（「%1$s被%2$s的爱之射线贯穿了」「正在追踪%s的 MRU 矩阵」）。
4. **标点**：一律全角；省略号用「……」；子类型用全角括号（「魔力动物分离器（成年）」）。
5. **希腊字母**当拉丁字母处理，和汉字之间加空格（「α 指环」）。
6. **物品名不带「的」**。「X之Y」只用于原作已有的系列（风之剑、火之魔晶、绿宝石之心），不新造。
7. **不用空泛后缀**：功能方块统一「……器」（合成器、繁殖器、剪毛器），不用「装置」「设备」「站」「机」；零件用具体名词（核心、框架、护板、透镜）。
   例外：**投影仪**（地脉投影仪，第五批）保留「仪」——「投影器」读着别扭，「投影仪」是现成的词。
8. **对齐原版官方中文**：锭、粉（不是「粉末」）、板、X块（金属块）、矿石、头盔/胸甲/护腿/**靴子**、重锤（Mace）、音乐唱片、摔落伤害、苦力怕、末地、下界、主世界、生物群系、精准采集、时运、烧炼、刻（tick）、刷怪蛋、物品栏。
9. **格式码**：原作饰品说明里的 `|a |c |6 |d |7 |r |n`（颜色/重置/换行）原样保留；新写的 tooltip 可以直接用 `§` 格式码。

## 三、系列词对照

- **四元素前缀**：物品系列用「火之 / 水之 / 地之 / 风之」（魔晶、焦点、水晶灯、魔晶块、护符）；燃料用「火 / 水 / 地 / 风元素燃料」。
  原作 Earth 混用「地」「土」（地之魔晶 / 土元素燃料 / 土灵之焦），统一「地」。
- **数学核心**：Addition / Subtraction / Multiplication / Division / Logic Core → **加法 / 减法 / 乘法 / 除法 / 逻辑核心**。
  原作误译成「附加 / 基础 / 增值 / 分裂 / 物流」，五个放在一起明显是一套运算。
- **力场零件**：Force → **力场**（力场吸收器、力场发射器），原作「强制吸收器」是把 force 当成「强制」。
- ~~**升级组件**：存储 / 效率 / 挖掘范围 / 冶炼 / 时运 / **精准采集** / 虚空升级。~~（已随采石场去掉，2026-09-28，policy §3.1）
- **盔甲**：头盔、胸甲、护腿、**靴子**（原作「之靴」「长靴」统一成原版的「靴子」）。
- ~~**魔力仓库（MIM）**：去掉原作名字里多余的「管理」：魔力仓库核心 / 存储模块 / 面板模块 / 合成模块 / 输入节点 / 输出节点 / 持续输入节点 / 持续输出节点。~~（整组已去掉，policy §3.1）
- **物品过滤器**（Item Filter）：白名单 / 黑名单 / 高级白名单 / 高级黑名单，写成「物品过滤器（白名单）」这样。原作叫「魔力仓库节点过滤器」，MIM 去掉以后给魔力漏斗用，改名（batch4 §3.6）。
